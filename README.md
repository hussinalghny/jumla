# تطبيق جملة · JUMLA App

تطبيق التجار لمنصة جملة (iOS + Android) بتصميم Apple، يقرأ مباشرة من `https://jumlapp.com/api`.
برمجة وتطوير **GHANI CODE** — https://ghanicode.com · © جميع الحقوق محفوظة.

## الشاشات
- **الرئيسية:** بحث، بطاقة المسار مع حركة السفينة، الأقسام، الأكثر طلباً، طلب تسعيرة، وصل حديثاً.
- **المتجر:** بحث، أقسام، ترتيب، تحميل تلقائي عند النزول (infinite scroll)، وسحب للتحديث.
- **المنتج:** معرض صور مع حركة Hero، المقاسات، كمية بالسيري، التكلفة الواصلة، المورد، ومنتجات مشابهة.
- **السلة:** التسعير من السيرفر عند كل تعديل، اختيار طريقة الشحن، والحذف بالسحب.
- **إتمام الطلب:** بيانات التوصيل وطرق الدفع، بعدها شاشة نجاح متحركة مع تعليمات الدفع.
- **طلباتي:** للمسجّلين قائمة الطلبات، وللزائر تتبع برقم الطلب والهاتف. شاشة الطلب بيها مراحل الشحنة متحركة.
- **حسابي:**
  - الدخول والتسجيل، وتعديل البيانات وكلمة السر.
  - طلبات التسعير وحاسبة الشحن.
  - تبديل العملة بين $ والدينار.
  - التواصل، وحذف الحساب (شرط من Apple وGoogle).

## الحركة
- كل الحركات قصيرة (160–420ms) وبمنحنيات ناعمة مثل iOS.
- الأزرار تصغر شوية عند اللمس، مع اهتزاز خفيف (Haptic).
- العناصر تظهر تدريجياً وبالتتابع.
- الصور تنتقل من البطاقة لصفحة المنتج (Hero).
- الأسعار والأرقام تتغير بحركة ناعمة.
- شارة السلة تقفز لما يتغير العدد.
- العناوين كبيرة وتنطوي عند النزول، والسحب للتحديث بأسلوب iOS.
- شاشة النجاح بيها علامة صح تنبثق.
- شريط تقدم الشحنة متحرك.

## التشغيل لأول مرة
المتطلبات: Flutter 3.27 أو أحدث، وXcode للآيفون، وAndroid Studio للأندرويد.

```bash
cd jumla_app
dart tool/setup.dart     # مرة وحدة: ينشئ مجلدات Android/iOS ويضبط الاسم والأيقونة وصلاحية الإنترنت
flutter run              # تشغيل على جهاز أو محاكي
```

## بناء نسخة النشر
```bash
flutter build apk --release          # أندرويد APK
flutter build appbundle --release    # Google Play
flutter build ipa --release          # App Store (يحتاج حساب Apple Developer)
```

## تغيير رابط الـ API
الرابط الافتراضي موجود بملف `lib/config.dart`، وتگدر تغيّره وقت البناء:
```bash
flutter run --dart-define=API_BASE=https://jumlapp.com/api
```

## البناء التلقائي على GitHub
ارفع المجلد على مستودع GitHub، والملف `.github/workflows/build.yml` يسوي لحاله:
- فحص الكود (`flutter analyze`) والاختبارات.
- بناء APK للأندرويد. تلگاه بتبويب **Actions** ← آخر تشغيل ← **Artifacts**.
- التأكد إن نسخة iOS تنبني بدون أخطاء.

## الهيكل
```
lib/
  config.dart          رابط الـ API
  theme.dart           الألوان والخطوط والحركة
  api/                 الاتصال بالسيرفر والنماذج
  state/app_state.dart السلة والحساب والعملة
  widgets/             الأيقونات (نفس أيقونات الموقع)، الأزرار، البطاقات
  screens/             كل الشاشات
assets/fonts           خط IBM Plex Sans Arabic (رخصة OFL)
assets/images          أيقونة التطبيق
tool/setup.dart        إعداد المشروع
```

## قبل النشر بالمتاجر
- غيّر `--org com.jumlapp` إذا تريد معرّف آخر، قبل ما تشغّل `setup.dart`.
- أندرويد: سوّي مفتاح توقيع (keystore) واضبطه بملف `android/key.properties`.
- iOS: افتح `ios/Runner.xcworkspace` بـ Xcode واختار الـ Team.
- عبّي بيانات الواتساب وتعليمات الدفع من لوحة تحكم الموقع، لأن التطبيق يقرأها من هناك.
